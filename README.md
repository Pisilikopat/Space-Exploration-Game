# Space-Exploration-Game

A simple console game written in Java.

How to Play

Choose coordinates on a 5x5 galaxy.

On planets: collect resources, refuel, or upgrade your ship.

Black holes may cause fuel or material loss.

The game ends when fuel runs out.

Menu

Requirements

Java 8+

Run

Run FinalP.java and follow the console instructions.
